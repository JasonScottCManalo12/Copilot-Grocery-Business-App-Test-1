# Grok Grocery Business App (Test-1)

A production-minded, offline-first Grocery Business App built with Flutter.

This repository is the active development workspace for the Grocery Business App, bootstrapped from the original planning repository.

## Project Goals

- **Android-first** offline-capable POS + Inventory system for a single grocery shop
- Clean architecture with shared business core
- Strict MVP discipline: Product → Stock → POS → Transaction → History
- Expand later into full multi-interface ecosystem (Owner, Staff, Customer, Accounting, etc.)
